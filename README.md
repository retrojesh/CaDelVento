# Ca' del Vento

Sito vetrina per la trattoria Ca' del Vento.

## Stack

- **Vite 8** — dev server e build
- **React 19** + **TypeScript 6**
- **Tailwind CSS 4** — via plugin `@tailwindcss/vite` (nessun `tailwind.config.js`: i token del tema si dichiarano in `src/index.css`)
- **Oxlint** — linting

## Comandi

```bash
npm install      # installa le dipendenze
npm run dev      # server di sviluppo su http://localhost:5173
npm run build    # build di produzione in dist/
npm run preview  # anteprima locale della build
```

## Sezioni previste

- Hero + Chi siamo
- Menu
- Galleria foto
- Contatti, mappa e orari

## Stato

Setup iniziale. Contenuti reali da inserire, foto e stile grafico ancora da definire.
